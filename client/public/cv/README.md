# CV / résumé

Place your CV PDF here.

## Instructions
1. Save the file as, e.g., khaled-helaly-cv.pdf.
2. Update src/data/profile.ts → esumeUrl to "/cv/khaled-helaly-cv.pdf".
3. The "Download CV" button is rendered only when esumeUrl is set; until then it stays hidden.

## OG image (also public/)
Place og-image.png (1200 × 630 px) directly in client/public/ and then enable the
commented og:image / 	witter:image tags in index.html and src/seo/seo.config.ts.
